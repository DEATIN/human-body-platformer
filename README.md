# ВНУТРИ · Путь кислорода

Небольшой учебный платформер по мотивам пользовательской концепции «ВНУТРИ». Ника поднимается на холм, а микрозонд Линза проходит условный маршрут внутри модели тела. Соберите три капсулы O₂, обойдите опасность и доставьте груз работающей мышце.

[Играть](https://deatin.github.io/human-body-platformer/) · [Репозиторий](https://github.com/DEATIN/human-body-platformer)

## Запуск

В папке проекта запустите:

```sh
python -m http.server 8000
```

Откройте [localhost:8000](http://localhost:8000/). Для ES-модулей нужен HTTP-сервер. Установка пакетов и сборка не требуются. Для GitHub Pages публикуется корень ветки `main`.

## Управление

- `←` / `→` или `A` / `D` — движение.
- `Пробел`, `↑` или `W` — прыжок.
- `P` или `Escape` — пауза и продолжение.
- `R` — начать заново.
- На телефоне удерживайте экранные кнопки движения; отдельная кнопка выполняет прыжок.

## Модель и реализация

Кислород переходит из воздуха в кровь при газообмене в лёгких, затем кровоток доставляет его к тканям, включая работающую мышцу. Вентиляция, газообмен и доставка — разные этапы. Этот мотив взят из разделов о дыхательной и сердечно-сосудистой системах предоставленного концепта.

Линза — вымышленный микрозонд. Платформы, прыжки и капсулы O₂ служат символами учебной аркады; они не изображают буквальную анатомию или движение клетки. Кислород не используется как универсальная валюта энергии. Полный PDF остаётся вне репозитория.

Игра написана на HTML, CSS и обычном JavaScript с ES-модулями. Игровое поле рисуется в Canvas; игровой движок и система сборки не используются. Изображения создаются программно, SVG-значок нарисован для этого проекта; внешних картинок нет.

Короткие звуковые сигналы синтезируются через Web Audio; внешние записи не используются. Звук выключен по умолчанию и переключается кнопкой «Звук».

## Использование AI

OpenAI Codex помог с кодом, оформлением и проверкой проекта. Сокращённые формулировки заданий, использованных при работе:

1. «Сделай учебный платформер “ВНУТРИ · Путь кислорода”: микрозонд Линза, минимум пять платформ, три капсулы O₂, опасность и финиш у работающей мышцы».
2. «Реализуй движение, гравитацию, прыжки и столкновения на JavaScript; игровой цикл с учётом времени кадра, паузу, продолжение и перезапуск».
3. «Оформи Canvas как стилизованную ткань по мотивам концепта; сохрани читаемость объектов и добавь экранные кнопки для телефона».
